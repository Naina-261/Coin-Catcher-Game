# Coin Catcher Game

A beginner-friendly 2D-style arcade game made with Unity and C#.

## How to play
- Move the basket with **A / D** or the **Left / Right Arrow** keys.
- Catch falling yellow coins to increase your score.
- Missing a coin costs one life.
- You have 3 lives.
- Press **R** to restart after Game Over.

## How to run
1. Install Unity Hub and a Unity 6 (6000.x) Editor.
2. In Unity Hub, choose **Add > Add project from disk**.
3. Select this `Coin-Catcher-Game` folder.
4. Open the project and open any scene (or create a new empty scene).
5. Press Play. The game creates its camera, basket, coins and score display automatically.

## Project contents
- `Assets/Scripts/CoinCatcherGame.cs` - game logic and automatic game setup.
- `Packages/manifest.json` - Unity package dependencies.
- `ProjectSettings/ProjectVersion.txt` - Unity editor version.

## Controls
| Key | Action |
|---|---|
| A / Left Arrow | Move left |
| D / Right Arrow | Move right |
| R | Restart |
